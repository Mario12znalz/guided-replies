Guided Replies — steer AI responses with a guidance prompt
When ON, the guidance prompt is injected before every generation.
Send: Injects the guidance prompt to steer the next response.
Regenerate: Uses the chat's first message as a style/quality reference and applies your guidance to fix the current response.
Write instructions for what you want the AI to do differently. In Regenerate mode, the first message is automatically used as a quality reference.
Use /guide preset <name> in chat to switch. Use /guide save <name> to save the current prompt as a preset.
